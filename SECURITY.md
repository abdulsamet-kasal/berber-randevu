# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to the project maintainers via [TBD]. We will acknowledge your report within 48 hours and provide a detailed response within 5 business days.

## Supported Versions

We provide security updates for the latest stable release.

## Security Best Practices

- Keep dependencies up to date.
- Use environment variables for secrets.
- Enable HTTPS in production.
- Regularly review access controls.
