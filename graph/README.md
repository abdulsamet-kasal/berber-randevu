# Proje Grafikleri

GitHub bu `.mmd` dosyalarindaki Mermaid diyagramlarini otomatik render eder.

## Icerik

| Dosya | Aciklama |
|---|---|
| 01-system.mmd | Sistem mimarisi (istemci, PHP, Supabase) |
| 02-database.mmd | Veritabani ER diyagrami (17 tablo) |
| 03-routes.mmd | Web + API route haritasi (12 sayfa + 22 API) |
| 04-backend-deps.mmd | PHP sinif bagimlilik grafigi (14 sinif) |
| 05-booking-sequence.mmd | Randevu akisi (sequence) |
| 06-auth-sequence.mmd | Login akisi (cookie + Bearer) |
| 07-admin-sequence.mmd | Admin panel akisi (filtre + CRUD + cache) |
| graph.json | Makine-dostu graf (nodes/edges) |
| project-stats.md | Dosya/satir istatistikleri |
