# Contributing to Berber Randevu

Thank you for considering contributing to Berber Randevu! Please read this guide before submitting any contributions.

## How to Contribute

1. Fork the repository on GitHub.
2. Create a new branch for your feature or bugfix.
3. Make your changes, ensuring they follow the coding standards.
4. Add or update tests as needed.
5. Commit your changes using conventional commits.
6. Push to your fork and submit a pull request.

## Coding Standards

- Follow PSR-12 for PHP code.
- Write clear, descriptive commit messages.
- Keep pull requests focused on a single issue.
- Update documentation when necessary.

## Reporting Issues

Please use the GitHub issue tracker to report bugs or request features.
